# MSPM0 Projects

TI MSPM0 系列 MCU 完整项目合集，包含 LC 测量仪、线长测量仪、功耗分析仪、D类功放、DDS信号发生器、数字万用表等。

## 项目列表

| 项目 | 说明 |
|------|------|
| LC-Measurer | LC 电感电容测量仪（含基础版和增强版） |
| Line-Length-Meter | 线长测量仪（3个版本） |
| Power-Analyzer | 功耗分析仪（含省赛版本） |
| Software-Marathon | 软件马拉松 |
| ClassD-Amp | D类功放自动音量控制 |
| DDS-Signal-Gen | DDS 信号发生器 |
| Digital-Multimeter | 数字万用表 |

## 硬件需求

- 主控芯片：MSPM0G3507 / MSPM0L1306
- 显示：0.96 寸 OLED（SPI/I2C）
- 传感器/外设：见各项目 README

## 软件环境

- IDE：Keil MDK-ARM / VS Code + Keil Assistant
- SDK：TI MSPM0 SDK
